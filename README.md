# Audience File Doctor

Public beta of Audience File Doctor.

Audience File Doctor validates, normalizes and prepares customer-list CSV files for upload to Meta Custom Audiences, Google Customer Match and LinkedIn Matched Audiences.

## Privacy

Customer-list files are processed locally in the user's browser. Do not commit or upload real customer CSV files, test exports, customer data, credentials, or secrets to this repository.

## Status

Public beta. Platform requirements can change; outputs should be reviewed before upload.
